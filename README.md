# ENT Case Pricer

CY2026 CMS Physician Fee Schedule work-RVU reference for head & neck / otolaryngology.
Select the codes performed; the page shows credited work RVUs (multi-procedure reduction,
bilateral, and add-on rules applied) and the documentation each code requires.

Live: https://cpt.ent-ai-agent.com

Single self-contained `index.html` — no runtime dependencies, and no data leaves the browser.

`index.html` is generated by
`aurelia-products/aurelia-notes/smartphrase-kit/build_calculator.py` in the private Aurelia
repository. SmartPhrase, SmartList, CPT, and documentation changes must be regenerated there and
then synchronized here; do not hand-edit the generated page.
